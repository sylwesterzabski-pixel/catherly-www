> ## **KAŻDA KARTA POZYCJI NIESIE POLE `DOTYKA` OBOK POLA `ZMIENIA`.**
> **Bez tego pola warunek jest apelem o czujność, a czujność zawodzi — udowodnione
> dziś kilkanaście razy.**

**Pole `ZMIENIA`:** klucze, których brzmienie pozycja zmienia.

**Pole `DOTYKA` — obowiązkowe, wypełniane przed wejściem pozycji:**

| co wymienić | dlaczego |
|---|---|
| **łańcuchy**, których nogą jest którykolwiek zmieniany klucz | zmiana jednej nogi rozbija łańcuch |
| **relacje podciągowe**, w których zmieniany klucz jest **dłuższy** | w środku siedzi cudzy ciąg |
| **klucze, dla których zmieniany ciąg jest JEDYNYM pokryciem** | §168 — naprawa nie może usuwać pokrycia, którego nie wymienia |
| **strażniki** (`e2e/`, `scripts/`) pilnujące zmienianego ciągu | 41 z 42 kluczy jest pod strażnikiem znak-w-znak (Z-12) |
| **wpisy rejestrów** (`liczby-w-tresci.json`, rejestr warunków powrotu, rejestr decyzji stojących) | zapis opisujący nie zamyka pozycji |

**Pole puste jest dopuszczalne wyłącznie jako `DOTYKA: sprawdzone, nic` — nigdy jako brak
pola.** Brak pola = pozycja nie wchodzi.
